How these scores are calculated

FinBERT is a classifier, not a generator: each headline goes in as plain text and the model directly outputs one of three labels — positive, neutral, negative — plus a calibrated confidence. There's no prompt and nothing to parse; the label is the answer.

An LLM like Qwen works differently: it's asked a question — "classify the sentiment of this headline as Positive, Negative, or Neutral" — and replies in free-form text. The code then has to search that reply for whichever of the three words appears first and use that as the label, since the model itself never outputs a structured score.

Each headline's label becomes a number — positive = +1, neutral = 0, negative = −1 — and the number on every card labeled sentiment (next to the rating pill) is the average of that across all headlines fetched for the ticker, so it ranges from −1 to +1. It's what decides BUY/HOLD/SELL: above +0.2 is BUY, below −0.2 is SELL, otherwise HOLD. It isn't a percentage and isn't related to the four price returns below it on the card — those come straight from Yahoo Finance.

This dashboard currently scores with FinBERT only, since it's fast enough to run unattended across 23 tickers every day. See the pipeline explainer for the full mechanics, including --compare mode, which runs both models side by side on demand.
